# ✉️ AI MailMate

AI MailMate is an ultra-fast, lightweight email drafting assistant built with Streamlit and powered by Groq's high-speed inference engine . It converts rough bullet points into structured, tone-customized emails in seconds.

---

## 🚀 Features

- **Fast Inference:** Near-instant email generation powered by Groq LPUs.
- **Tone & Length Control:** 5 distinct tones (Professional, Friendly, Persuasive, Direct, Apologetic) and 3 length presets.
- **Clean UI:** Distraction-free, responsive layout.

---

## 🛠️ Tech Stack

- **Frontend & UI:** Streamlit
- **LLM Engine:** Groq Cloud API 
- **Language:** Python 3.10+
